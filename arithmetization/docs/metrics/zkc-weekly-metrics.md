# RISC-V arithmetization weekly metrics

Generated by `.github/workflows/arithmetization-weekly-zkc-metrics.yml`, which runs
`arithmetization/src/test/scripts/weekly_metrics`. **Newest run first.** Rows are appended
under each table's `<!-- table:… -->` marker; the prose around them is free to edit.

The measured workload is the l2-execution guest built with `KECCAK_ACCEL=true`, run against
`riscv-guests/l2-execution/test/testdata/stateless_input.ssz` — the small committed reference
block. Each cell in the cost table reads `outcome wall / peak RSS`.

The `d8+` column is zkc's final degree bucket whatever it is currently labelled: it reads `d8+`
while nothing has reached degree 8 and closes to `d8-d<max>` once something does. Read the
`max degree` column for the actual maximum. The trace and trace+check steps are best-effort and
capped, so a `TIMEOUT` cell is a genuine data point — the cost exceeded the cap that week.

A row whose runner cell reads **run lost** means the job never completed — evicted, cancelled or
out of memory — so no measurement exists for that week. It is recorded deliberately: a missing week
would otherwise be indistinguishable from a week nobody ran.

The first row was harvested by hand on a laptop, which is why its runner differs; every later row
comes from the fixed CI tier.
